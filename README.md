# Negative-Free Self-Supervised Gaussian Embedding of Graphs

Official Implementation of Negative-Free Self-Supervised Gaussian Embedding of Graphs (Neural Networks 2024).



## Dependencies

- dgl
- torch
- scikit-learn



## Reproduction

Copy hyper-parameters from [params.txt](./params.txt) to [main.py](./main.py) and run it.
